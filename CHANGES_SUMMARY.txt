一、新增：地面平面拟合（FitGroundPlane）
--------------------------------------------------------------------------------
文件: src/Tracking.cc (约L6200-L6270)

功能: 在初始化阶段从静态特征点拟合地面平面。
  - 收集地面附近地图点的相机-点向量
  - RANSAC拟合平面法向量n和偏移量d
  - 存入Map: mPlaneNormal, mPlaneRefOffset(冻结), mPlaneRefHeight

数据流:
  FitGroundPlane → mPlaneNormal, mPlaneRefOffset(冻结锚点), mPlaneRefHeight
  首次拟合后 d_ref 冻结，不再修改。

文件: include/Map.h, src/Map.cc
  + mPlaneNormal, mvpPlaneOffsets, mPlaneRefHeight, mPlaneRefOffset, mPlaneDynamicOffset
  + SetPlaneModel(), GetPlaneNormal(), SetPlaneRefOffset(), GetPlaneRefOffset()
  + SetPlaneRefHeight(), GetPlaneRefHeight(), SetPlaneDynamicOffset(), GetPlaneDynamicOffset()

二、新增：PlaneRemark 每30帧平面点动态标记
--------------------------------------------------------------------------------
文件: src/Tracking.cc (约L6374-L6445)

功能: 每30帧刷新哪些地图点被标记为"平面点"，并更新 d_dynamic。

步骤:
  步骤1: d_dynamic = median(n·P_已标记点)    // 用于三角化和标记
  步骤2: 重新标记平面点:
         - 过滤条件: |n·P - d_dynamic| < |d_dynamic|*0.6  (距离阈值)
         - 高度守卫: t_triang/t_plane < 0.35 → 排除建筑立面
         - 物理守卫: ndir < 0 (射线朝向地面)
         - 标记: mnPlaneID=0, mfPlaneInfo=1.0
  步骤3: d_dynamic = median(n·P_标记点) -> SetPlaneDynamicOffset()

三、新增：三角化平面引导（α-fusion）
--------------------------------------------------------------------------------
文件: src/LocalMapping.cc (约L694-L720) - CreateNewMapPoints()

功能: 低视差时三角化深度退化，用射线-平面交会深度替代。

  d_dynamic = GetPlaneDynamicOffset()  (或fallback到d_ref)
  t_plane = (d_dynamic - n·Ow1) / ndir          // 射线到平面距离
  t_triang = |x3D - Ow1|                        // 两视图三角化深度

  α = f(cosParallaxRays):
    cosPara > 0.9998  → α=1.00  (纯旋转, 全信平面)
    cosPara > 0.9995  → α=0.75  (转弯)
    cosPara > 0.9990  → α=0.50  (弱视差)
    cosPara > 0.9980  → α=0.25  (过渡)
    else              → α=0     (好三角化, 不干预)

  低视差Guard: heightRatio = t_triang/t_plane > 0.3
  物理Guard: ndir < 0 (射线向下)

  x3D = Ow1 + dir * (t_triang + α*(t_plane - t_triang))

四、恢复：EdgePlaneConstraint（BA中极轻平面软约束）
--------------------------------------------------------------------------------
文件: src/Optimizer.cc (6个BA函数各1处)

功能: 对标记点(mnPlaneID>=0)施加info=1.0的平面约束
  error = n·P_optimized - d_ref
  info = 1.0 (固定，远小于重投影info≈10000)

覆盖BA函数:
  1. BundleAdjustment (Global BA, Line ~193)
  2. FullInertialBA (Line ~660)
  3. LocalBundleAdjustment(KeyFrame*) (Line ~1405)
  4. LocalInertialBA (Line ~2851)
  5. MergeInertialBA (Line ~3783)
  6. LocalBundleAdjustment(KeyFrame*, vector...) (Line ~4447)

注意: 仅恢复了EdgePlaneConstraint(点级)，没有恢复KF级约束(EdgeKFCamCenterToPlane*)。

六、当前有效代码总览
--------------------------------------------------------------------------------

平面模型生命周期:
  FitGroundPlane(一次性) → mPlaneNormal, mPlaneRefOffset(冻结), mPlaneRefHeight
         │
  PlaneRemark(每30帧) ← median(n·P标记点)
         │
         ├─→ mPlaneDynamicOffset (用于三角化)
         └─→ 标记mnPlaneID=0 (用于BA EdgePlaneConstraint)
                │
  LocalMapping(每新KF) ← d_dynamic
         │
         └─→ α-fusion: t_plane引导三角化深度 (ndir<0, heightRatio>0.3)

  Optimizer(每BA) ← mnPlaneID>=0
         │
         └─→ EdgePlaneConstraint info=1.0: 极轻平面残差

七、待尝试: 回环检测阈值放宽
--------------------------------------------------------------------------------
建议在 LoopClosing.cc DetectCommonRegionsFromBoW() 中调整:
  nBoWMatches:  20 → 12
  nBoWInliers:  15 → 10
  nSim3Inliers: 20 → 15
  nProjMatches: 50 → 30

      Sim(3)的scale分量自然修正尺度漂移。
